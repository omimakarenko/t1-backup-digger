What this tool does

Torso saves each Bank as its own file. This tool moves, copies, and rearranges those files between backups — it never opens or changes what's inside a pattern, so there's no way it can touch your patterns, CC data, or anything else you've programmed.

Drag a bank from any loaded backup straight into New Project to use it there — the original stays put, so the same bank can go into several slots if you want. Dragging the whole cell carries its current save and its previous save together; grab just one specific version instead from the small arrow icon in the corner.

Many banks have an earlier saved version sitting right behind the current one. When that's the case, hover the arrow icon to see every version you've got for that bank — across every backup you've loaded, not just this one — or click it to pin the list open while you drag pieces around. It's the easiest way to dig up an old take you thought was gone.

Each loaded backup can carry its own notes — click "add a note" under any project to jot down what's in it. Notes are saved right inside the .zip itself, so they're there again next time you drop that same file back in, even on a different computer.

Want to reorganize a backup itself, not just build something new from it? Click "rearrange cells" on any loaded project to drag banks around within it — or between two backups you've both put in rearrange mode — then "save & download copy" for a new .zip with the new layout. Replace your old file with it to keep the change.

Right-click any bank to Copy it, then right-click an empty or filled cell to Paste — handy for stamping the same starter template (a scale, a CV setup, whatever you like to improvise from) into several slots at once, in New Project or while rearranging a backup.

Torso's Project backup format has changed across firmware versions over the T1's life, and this tool only understands the current one, introduced in firmware 2.1. Backups made on much older firmware may not open correctly here.

Something you might want to know: inside Torso's own backup files, numbering starts from 0 — so what this tool (and the device screen) calls banks 1–16 are technically cells 0–15 on disk. Only matters if you're ever poking at the .zip by hand.
